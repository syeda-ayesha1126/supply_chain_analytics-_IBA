##  About

This repository contains coursework and project work for **Supply Chain Analytics at IBA Karachi**, taught by **Sir Faisal Jalal**.

Using **Chilli Milli by Ismail Industries Limited** as the focal product, the project explores **forecasting, inventory, sourcing networks, risk, ESG, and AI-assisted supply chain decision-making**.
